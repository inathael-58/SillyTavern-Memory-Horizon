# Memory Horizon — SillyTavern extension

บอกว่า **AI ยังจำย้อนได้ถึงข้อความไหน** และ **อะไรกิน context** — ไม่ใช่แค่ว่า "เต็มกี่ %"

ในแชทยาว SillyTavern จะใส่ประวัติแชทจนเต็มงบทุกครั้ง ตัวเลข 90%+ จึงเป็นเรื่องปกติ ไม่ใช่สัญญาณอันตราย
Memory Horizon เลยวัดสิ่งที่ควรรู้จริง ๆ:

- **ขอบความจำ** — AI ยังเห็นย้อนได้กี่ข้อความ ลืมไปแล้วกี่ข้อความ ข้อความเก่าสุดที่ยังจำได้คืออันไหน
- **ที่ว่างก่อนเริ่มลืม** — ตอนแชทยังสั้น เหลืออีกกี่ token ก่อนข้อความแรก ๆ จะเริ่มหลุด
- **อะไรกิน context** — แยกเป็นประวัติแชท / ที่แทรกตามความลึก (preset หรือ extension ที่ตั้ง @D) / การ์ด / Lorebook / Preset / เพอร์โซนา / ตัวอย่างบทสนทนา / ส่วนเสริม · อยากเห็นละเอียดถึงระดับ entry หรือ extension ทีละตัว กด **ละเอียดใน Lore Lens** (ถ้าติดตั้งไว้)
- **ต่อกับ Memory Hub** — ถ้ามีข้อความหลุดจากความจำไปโดยยังไม่ได้สรุป จะบอกให้รู้

## ทำไมไม่เตือนมั่ว

- ใช้ตัวนับ token ของ Prompt Manager ตรง ๆ (ตัวเดียวกับที่ ST ใช้ตัดประวัติ) ไม่นับใหม่เอง ตัวเลขจึงตรงกับ ST
- ไม่นับ token "ไม่มีชื่อ" ที่ตัวนับของ ST สะสมไว้ ซึ่งพองเป็นหลักแสนได้ตอนเปิด **Squash system messages** (ST นับข้อความที่รวมแล้วซ้ำทุกครั้งที่ต่อชิ้นใหม่ ทั้งที่ไม่ได้ส่งจริง)
- ขอบความจำใช้วิธีเดียวกับเส้นประ `lastInContext` ของ ST
- รับเฉพาะรอบที่คุณ **ส่ง / สุ่มใหม่ / ต่อข้อความ** จริง — ไม่รับงานเบื้องหลังของ extension อื่น (quiet prompt, `generateRaw` เช่น ตอน Memory Hub หรือ Lore Master สั่งโมเดล)
- รอบจำลอง (dry run) ใช้แสดงค่าประมาณ (มีเครื่องหมาย ≈) แต่ไม่ปลุกการเตือน
- ST จำลองพรอมท์เองทุกครั้งที่ AI ตอบเสร็จ แต่รอบจำลองข้าม interceptor ของ extension (เช่น Memory Hub ตัดข้อความที่สรุปแล้วออก) และไม่ squash — ตัวเลขจึงยึดรอบที่ส่งจริงไว้ ไม่ให้รอบจำลองนั้นมาทับ (ข้อความใหม่ที่ต่อท้ายนับสดให้เอง) · รับค่าจำลองเฉพาะตอนยังไม่มีผลจริง มีข้อความถูกลบ หรือเปลี่ยนการตั้งค่า
- นับข้อความแชทจากที่ ST ประกอบไว้ก่อน extension อื่นแก้พรอมท์ แล้วจับคู่กับแชทจริง ข้อความที่ preset หรือ extension แทรกตามความลึกจึงไม่ถูกนับเป็นแชท
- เปลี่ยนพรีเซต โมเดล หรือขนาด context กลางแชท ตัวเลขเดิมจะไม่ถูกใช้ต่อ ป้ายขึ้น **กำลังคำนวณ…** แล้วจำลองพรอมท์ใหม่ให้เอง (ไม่ได้ส่งอะไรให้โมเดล)
- เตือนครั้งเดียวต่อการที่สถานะแย่ลง ไม่เตือนซ้ำทุกข้อความ

| สถานะ | เมื่อไหร่ |
|---|---|
| ปกติ | ทุกกรณีที่เหลือ — รวมถึงตอนพรอมท์เต็มงบ |
| ระวัง | จำย้อนได้น้อยกว่าที่ตั้งไว้ · ส่วนที่ส่งทุกรอบกินงบเกินที่ตั้งไว้ · ข้อความหลุดไปโดย Memory Hub ยังไม่ได้สรุป |
| เกินงบ | พรอมท์เกินงบจริง (เผื่อ 2%) หรือไม่มีข้อความแชทถูกส่งไปเลย |

## ป้ายแสดงผล

เลือกได้หลายจุดพร้อมกัน แต่ละจุดเลือกขนาดเองได้ (มินิ / ย่อ / เต็ม)

| จุด | หน้าตา |
|---|---|
| เกาะขอบแถบพิมพ์ | ป้ายเล็กลอยเหนือขอบบนของแถบพิมพ์ ไม่เบียดช่องพิมพ์ (ค่าเริ่มต้น) |
| เส้นบนช่องพิมพ์ | เส้นไทม์ไลน์บาง ๆ พาดขอบบน (แบบย่อ/เต็มมีป้ายตัวเลขเล็ก ๆ ถ้าไม่ได้เปิดป้ายเกาะขอบ) |
| หัวแชท | ป้ายลอยกลางขอบบนของแชท |
| ปุ่มลอย | ลากวางได้ ดูดติดขอบ · เก็บเข้า **Quick Dock** ได้ |

ป้ายเกาะขอบและป้ายบนเส้นเลือกได้ว่าจะอยู่ฝั่งซ้ายหรือขวาของแถบพิมพ์ · แบบย่อแสดง 2 ช่องแรกที่มีค่า แบบเต็มแสดงทุกช่อง · ค่าประมาณ (จากรอบจำลอง) แสดงเป็นจุดสถานะแบบวงกลวง

ข้อมูลบนป้ายเลือกเองได้: จำย้อนได้กี่ข้อความ · ที่ว่างก่อนเริ่มลืม · ลืมไปแล้วแต่ยังไม่ได้สรุป · ลืมไปแล้วกี่ข้อความ · token ที่ส่ง/งบ · % ของงบ — ช่องที่ไม่มีค่าจะซ่อนเอง

แตะป้ายไหนก็ได้เพื่อเปิดหน้ารายละเอียด ปิดได้ด้วยการแตะที่ว่าง ปัดลง หรือกด Esc

### ใช้กับ Quick Dock

- เปิด **ปุ่มลอย** แล้วเก็บเข้าถาด Quick Dock ได้ตามปกติ
- ปุ่มส่งสถานะผ่าน `data-state` ให้ Quick Dock ปุ่มหลักจะมีจุดแจ้งเตือนเมื่อสถานะเป็น "ระวัง" หรือ "เกินงบ" ไม่ต้องเปิด dock มาดู
- หน้ารายละเอียดไม่ได้ติดอยู่กับ dock แตะที่ว่างก็ปิด ไม่ต้องกลับไปแตะ dock อีกรอบ
- หรือไม่ใช้ปุ่มลอยเลย ใช้ชิปในแถบพิมพ์แทน แล้วผูกคำสั่ง `/horizon` เป็นช็อตคัทใน Quick Dock

## ในแชท

- **เส้นขอบความจำ** “AI จำได้ตั้งแต่ตรงนี้” บนข้อความเก่าสุดที่ยังอยู่ในความจำ (แทนเส้นประจาง ๆ ของ ST)
- เลือกให้ข้อความที่ AI ลืมแล้วจางลงได้
- ปุ่ม **ไปที่ขอบความจำ** ในหน้ารายละเอียด

## สีตามธีม

ไม่มีสีฝังตายตัว — ทุกสีผสมจากตัวแปรธีมของ SillyTavern (`--SmartThemeBodyColor`, `--SmartThemeQuoteColor`, `--SmartThemeBorderColor`, `--SmartThemeBlurTintColor` …)
เปลี่ยนธีมมืด/สว่างแล้วสีเปลี่ยนตามทันที ไม่ต้องเขียน CSS override เลือกได้แค่ว่าจะดึงสีเน้นจากช่องไหนของธีม

## อัปเดต

หัวข้อในหน้า Extensions แสดงเลขเวอร์ชันที่กำลังรัน ปุ่ม **เช็คเวอร์ชัน** เทียบกับไฟล์บนเซิร์ฟเวอร์ และ **โหลดเวอร์ชันล่าสุด** ดึงไฟล์ใหม่ทั้งหมดแล้วรีโหลด (ใช้เมื่อกด Update แล้วเบราว์เซอร์ยังจำไฟล์เก่า โดยเฉพาะบน iOS) ถ้าติดตั้งเวอร์ชันใหม่ไว้แต่หน้ายังรันของเก่า จะมีป๊อปอัปบอกให้แตะโหลดใหม่

## ข้อจำกัด

- รายละเอียด token มีเฉพาะโหมด **Chat Completion** · โหมด Text Completion ใช้ได้เฉพาะขอบความจำ
- ข้อความที่ extension อื่นแทรกเข้าไปในประวัติแชทด้วย role user/assistant อาจทำให้ขอบความจำคลาดไป 1–2 ข้อความ (ST ก็นับแบบเดียวกัน)
- แชทที่ยังไม่เคยวัดในเวอร์ชันนี้จะใช้ค่าประมาณจากข้อมูลเดิมของ ST จนกว่าจะส่งข้อความหรือกด "วัดตอนนี้"
